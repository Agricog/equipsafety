# EquipSafety - Care Home Equipment Safety

Multi-language equipment safety instructions via QR codes for UK care facilities.

## Quick Deploy to Railway

1. All files uploaded to GitHub in correct structure
2. Go to railway.app
3. Click "New Project" → "Deploy from GitHub"
4. Select equipsafety repo
5. Railway will auto-detect Vite
6. Add custom domain equipsafety.co.uk
7. Update SmartSuite webhook URL in src/App.jsx (line 27)
